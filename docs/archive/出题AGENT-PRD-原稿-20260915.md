### 1.1 背景

高校教师出题通常需要反复查看教材、PPT 和往年试卷，人工统计知识点覆盖、控制难度梯度和编写答案解析，耗时较长。

ExamPilot 希望利用 AI Agent 将出题流程拆分为 规划 → 出题 → 修改 三个阶段，在保证知识点覆盖和引用可追溯的前提下，提高出题效率

### 1.2 目标

用户可以：

- 设置试卷结构（题型、分数、难度）。
- 上传教材、PPT 等课程资料。
- AI 自动分析知识点并规划试卷结构。
- 多轮调整组卷方案。
- 生成完整试卷，并提供答案、知识点解析和原文依据。
- 人工修改后导出最终试卷。

### 1.3 非目标（本期不做）

不做批改
		仅针对用户上传的资料做全面的知识点提取和出题，不对章节单元进行划分

## 编辑能力

用户可以：

| 操作       | Agent 行为             |
| ---------- | ---------------------- |
| 编辑题目   | 保留答案与解析同步更新 |
| 删除题目   | 自动保持总分结构       |
| 补充同类题 | 保持知识点与难度一致   |
| 修改难度   | 重新生成对应版本       |
| 修改知识点 | 重新生成对应题目       |

例如：

> “把这道 SQL 选择题改成中等难度。”

Agent 会重新生成，而不是简单改几个词。

这一点体现了参考架构中的 Orchestrator：Agent 能重新调用生成能力，而不是一次性输出。

提供两个导出版本：

| 按钮         | 内容                         |
| ------------ | ---------------------------- |
| 导出试卷     | 学生版                       |
| 导出答案解析 | 教师版（答案+解析+原文依据） |

教师版示例：

| 内容     | 示例          |
| -------- | ------------- |
| 答案     | B             |
| AI解析   | 为什么选B     |
| 原文依据 | 教材18页第3段 |

它不是“帮老师生成题目”的聊天机器人，而是一个会规划→分析→迭代→执行→校验的智能组卷 Agent

        老师上传教材/PPT/题库

                  │
                  ▼

### 对应关系

| 用户看到     | 底层能力         |
| ------------ | ---------------- |
| 上传资料     | 知识点提取 Skill |
| AI组卷       | Orchestrator     |
| 原文依据     | GraphRAG 检索    |
| AI解析       | LLM 生成         |
| 再生成同类题 | Tool Calling     |
