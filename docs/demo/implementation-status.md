## 已执行检查

- Python 自动化：25 项测试通过，包含 262,701 组分题型难度分配组合，以及控制字符导出回归测试。
- 解析：真实生成的文字 PDF／DOCX／PPTX 验证来源定位；空白 PDF 被拒绝。
- 后端集成：真实 FastAPI、SQLite、独立 MCP 进程，覆盖六题型生成、两次工具调用与多题证据复用。
- 交互规则：删除后才可补题；两轮候选不提前计分；采纳幂等；采纳后不能撤销原删除而重复加题。
- 校验：生成中拒绝编辑、过期版本拒绝、手动编辑需重新复核、显式修改目标分值后可导出。
- 来源：跨项目 Chunk 不可读取；篡改原文后阻止导出。
- Word：实际生成、读取 DOCX ZIP 内容，学生版不含教师答案解析、知识点及来源字段。
- 前端：TypeScript 检查与 Vite 生产构建通过。
- 浏览器：Chrome headless 跑通上传→分析→规划调整→13 题→删除→两轮候选→来源侧栏→采纳→Word 下载，无 JS 运行时错误。
- 窄屏：390 px 视口无页面横向溢出。

## 验证边界

模型响应采用**测试目录内的确定性替身**，不接入正式产品；MCP、数据库、业务接口、页面操作和 Word 导出均是真实执行。测试没有证明模型回答的事实正确性或三家供应商账号可用。

初次实现时运行环境未提供 `EXAMPILOT_API_KEY`，随后用户已在设置页配置系统凭据，模型列表实测情况见顶部修复记录。仍需分别选择三家具体模型完成原生工具调用、出题质量和实际耗时验收。API Key 不应写入 PRD、测试或验收文档。

PRD 的 36 条验收用例不全等同于这 25 项自动测试。扫描件／复杂图文边界、真实模型限流和截断、资料事实矛盾、语义重复、复杂计算正确性，以及人工 Word 版式审阅还需更多样例验证。

## 本期有意后置或当前简化

- GraphRAG、向量索引、公网多用户与独立分布式任务队列后置。
- 普通文字、基础表格采用固定 Word 排版；不承诺复杂公式或学校模板。
- 数学正确性目前由模型复核和教师检查，未集成通用求解器。
- 相同题干可检测；语义近似重复尚无独立向量去重。
- 缓存以查询和资料版本进行复用；当前未单独提供可视化 Manifest 管理器。
- 文档处理每块可恢复；一个项目最多 5 个文件、单文件 20 MB、总提取文本 30 万字符。
