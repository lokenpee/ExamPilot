## HTTP 400 的原因与修复

实际服务商错误：`Thinking mode does not support this tool_choice`。DeepSeek Flash 默认开启思考模式，而本项目需要指定工具调用。已显式使用该模型支持的非思考模式，并保留模型名称。

后续工具调用消息会保留服务商要求的 continuation 字段，仅用于 API 往返，不展示或记录内部推理。能力测试现为三个真实步骤：结构化输出、原生工具调用、回传工具结果后继续响应。服务端错误信息在脱敏后显示具体原因。

参考：[DeepSeek 模型说明](https://api-docs.deepseek.com/quick_start/pricing)、[Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode)。
